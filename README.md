# Каналья!

Лендинг виджета, который показывает на сайте сообщества настроение его чата в Telegram, и гардероб с двенадцатью костюмами виджета.

Сайт статический: сборка не нужна, сервер не нужен. Всё, что лежит в этой папке, загружается как есть.

## Что где

| Путь | Что это |
| --- | --- |
| `index.html` | Лендинг |
| `garderob/index.html` | Гардероб: все костюмы в свёрнутом и открытом виде |
| `c/` | Герои и летуны лендинга |
| `p/` | Реквизит: стикеры, мемы, гифки, предметы, пасхалки |
| `h/`, `garderob/h/` | Талисманы, которые выглядывают из-за виджета |
| `favicon.svg`, `og.jpg` | Значок вкладки и картинка для ссылок в мессенджерах |
| `.nojekyll` | Пустой файл: просит GitHub отдавать папку без обработки |

Пути внутри страниц относительные, поэтому сайт работает и в корне домена, и в подпапке вида `имя.github.io/репозиторий/`.

## Как выложить на GitHub Pages

1. Создать репозиторий на github.com.
2. Загрузить в него содержимое этой папки целиком: кнопка «Add file» → «Upload files», перетащить все файлы и папки. Файлы `.nojekyll` и `.gitignore` скрытые: в Finder их показывает Cmd + Shift + точка.
3. Открыть Settings → Pages. В «Build and deployment» выбрать Source: «Deploy from a branch», ветку `main`, папку `/ (root)`. Сохранить.
4. Через минуту-две сайт откроется по адресу `https://<имя>.github.io/<репозиторий>/`, гардероб — по адресу `…/garderob/`.

Проверить локально: открыть `index.html` двойным кликом.

## Что поправить перед запуском

- **Имя бота.** В `index.html` найти строку `var BOT_USERNAME = '';` и вписать имя без «@». Кнопка «Написать боту» станет ссылкой на `t.me/<имя>`. Пока имя пустое, кнопка никуда не ведёт.
- **Адрес скрипта.** В блоке «Три касания до виджета» показана строка с адресом `https://kanalya.example/w.js`. Это заглушка: заменить на настоящий адрес, когда он появится.
- **Картинка для ссылок.** Мессенджеры берут `og:image` только по полному адресу. После публикации заменить в обоих `index.html` значение `og.jpg` (и `../og.jpg` в гардеробе) на `https://<имя>.github.io/<репозиторий>/og.jpg`.
- **Шрифты.** Декоративные шрифты ST встроены прямо в страницы. У ST Bubblegum и ST Stengazeta в метаданных файлов указано EULA, а не Free: перед публичным запуском проверить условия лицензии.
